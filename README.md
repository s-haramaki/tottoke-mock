# 操作モック

`index.html`をブラウザで開くと、主要な撮影・保存導線を操作できる。

レビュー時は`review.html`を開く。テスト設定や説明を隠し、端末画面だけに集中できる表示で起動する。

GitHub Pagesでは、公開URLの`review.html`がレビュー専用表示になる。公開用リポジトリの`main`ブランチ更新時に`.github/workflows/pages.yml`から再公開する。

## 試せること

- おすすめ内容からの撮影
- 年齢に合う質問・日常の撮影内容を一覧から選択
- 0歳から使える定点シチュエーション5案の選択、撮影前の短い映り込み注意、同じ内容での比較
- 自由入力からの撮影
- 録画開始・停止
- 撮り直し確認
- 動画生成・保存完了
- 生成失敗・再試行・削除終了
- ライブラリでの保存済み動画一覧と比較案内
- 記録詳細からの再生・写真アプリ／ファイルへの書き出し・削除確認
- 設定からのプロフィール単位一括書き出し、完了・部分失敗・再試行
- 録画前・生成前・一括書き出し前の容量不足チェックと再確認
- 録画停止後の一時保存、再試行、復旧不能時の撮り直し
- 保存後のファイル破損検出、テロップ動画の再生成、復旧不能記録の削除
- 個別書き出し失敗と削除途中失敗からの再試行

画面右側の「次の動画生成を失敗させる」は、生成失敗フローを確認するためのモック専用設定。スマートフォン幅では非表示になる。

改修後は、画面右側の「最新版をリロード」でページ全体を再読み込みできる。

表示上のアプリ名は`index.html`の`appDisplayName`へ集約し、正式名称の「とっとけ」を表示する。
